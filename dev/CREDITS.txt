This software uses third-party libraries. Those include:

	Tooling-UI: Dear ImGui - https://github.com/ocornut/imgui

	Font-Loading: FreeType - https://freetype.org/

	TextEditor: Zep - https://github.com/Rezonality/zep

	Nodegraph-Editor: Node Editor in ImGui - https://github.com/thedmd/imgui-node-editor

	Model-Loading: Open Asset Import Library (assimp) - https://github.com/assimp/assimp

	Font-Generation: Multi-channel signed distance field generator - https://github.com/Chlumsky/msdfgen

	Scripting-Language: Python3 - https://www.python.org/
