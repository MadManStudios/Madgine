Starting the Engine
~~~~~~~~~~~~~~~~~~~

When starting the engine the first time, you are presented with a blank screen and only two items in the menu bar and the :ref:`log-viewer`. By default all plugins are disabled, except those that are dependencies of the launcher itself. To get started you can open the Plugin Manager tool and enable all plugins you intend to use. To do this open the :ref:`plugin-manager` and select the necessary plugins to work with.

.. image:: /docs/img/screenshots/pluginmanagermenu.png

Afterwards, you should create/load your project by providing the engine with the root folder of your game.
