Detailed Description

The Application manages all GlobalAPIComponents.

The Application creates all registered GlobalAPIComponents. It also creates a TaskQueue for game logic tasks.

Engine::Core::Application::Application ( )

Creates an Application and sets up its TaskQueue.

Instantiates all WindowAPIComponents. Initialization/Deinitialization-tasks of the MadgineObject are registered as setup steps in the TaskQueue.
